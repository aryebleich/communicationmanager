# Relay — Voice & messaging, on your terms

A responsive, static landing page for a code-managed communications stack built around Asterisk/FreePBX for voice and carrier webhooks for SMS/MMS.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. There is no build step or package installation.

## Publish

The site is static and can be published with GitHub Pages from the repository's `main` branch and root directory.

## Notes

The code examples are illustrative, not drop-in production integrations. Add carrier-specific webhook signature verification, protect management interfaces, and consult current vendor installation and configuration documentation before deployment.
