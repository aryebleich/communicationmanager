02 / THE BLUEPRINT

From server
to first call.

A practical path from an empty Linux host to a connected communications stack. Start small, secure each layer, then add application logic.

Jump to the code ↓
01—04
01

Prepare your voice server

ASTERISK + FREEPBX

Choose a supported Linux host, install Asterisk and FreePBX using their current official documentation, and complete initial setup. Confirm version and OS compatibility before you deploy.

↳ Keep the admin interface behind a VPN or trusted access policy.
02

Connect a SIP trunk

VOICE CARRIER

Choose a provider that supports your region and use its trunking guide to configure authentication, endpoint, and caller ID. Test inbound and outbound calling separately.

↳ Use a dedicated trunk credential; never reuse an admin password.
03

Give your app a voice interface

AMI / ARI

Use AMI for manager events and actions, or ARI for application-driven call control. Create a least-privilege account and keep management ports private.

↳ Prefer ARI for new application-controlled call flows.
04

Route messages to your app

SMS WEBHOOK

Point your carrier’s inbound messaging webhook at an HTTPS endpoint. Validate the provider’s signature, acknowledge quickly, and process messages asynchronously.

↳ For high-volume direct SMPP, evaluate a gateway like Jasmin.
03 / FOR DEVELOPERS

Your app is
in the conversation.

Keep the integration thin: your carrier delivers the message, your endpoint verifies and accepts it, and your application decides what happens next.

import express from 'express';
const app = express();
app.use(express.json());

app.post('/sms-webhook', async (req, res) => {
  // Verify the carrier signature before trusting this payload.
  if (!verifyCarrierSignature(req)) {
    return res.sendStatus(401);
  }

  const { from, to, text } = req.body;
  await enqueueInboundMessage({ from, to, text });
  res.sendStatus(200);
});

app.listen(process.env.PORT ?? 3000);
// Keep AMI reachable only on a trusted network.
const ami = new AmiClient({
  host: process.env.AMI_HOST,
  port: 5038,
  username: process.env.AMI_USERNAME,
  password: process.env.AMI_PASSWORD,
});

ami.connect();
ami.on('managerevent', (event) => {
  if (event.event === 'Newchannel') {
    console.log('New channel started');
    // Avoid logging phone numbers or message contents.
  }
});
